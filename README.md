# 🌐 JavaScript API Dashboard

A **dynamic, interactive API Dashboard** built with **HTML, CSS, and JavaScript**, showcasing multiple public APIs. This project is perfect for learning **fetch requests, async/await, DOM manipulation**, and building **portfolio-ready web apps**.

---

## 🎯 Features

- 🐶 **Random Dog Images** – Fetches images from Dog CEO API  
- 🐱 **Random Cat Images** – Fetches images from The Cat API  
- ☀️ **Weather Info** – Fetches current weather (API key required if using OpenWeatherMap)  
- 💱 **Currency Exchange Rates** – Fetches latest currency rates  
- 🎮 **Trending Movies / No-key API** – Fetches random movies using a public JSON file  
- 🧑‍💻 **GitHub User Info** – Fetch public info of any GitHub user  
- ⚡ **Random Pokémon** – Fetches 3 random Pokémon with images, type, and HP  
- 🤣 **Random Jokes** – Fetches jokes from Official Joke API  

---

## 🚀 Live Preview

Click the buttons to fetch and display data from each API in a **Netflix-style grid**. Fully responsive and interactive.

---

## 🛠️ Technologies Used

- **HTML5 & CSS3** – Responsive grid layout, hover effects, card design  
- **JavaScript (ES6)** – Async/Await, Fetch API, DOM manipulation  
- **APIs** – Dog CEO, The Cat API, PokeAPI, GitHub API, Public APIs JSON, Official Joke API
